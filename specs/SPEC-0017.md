## Abstract

Defines the `RunManager` high-level lifecycle service: its construction, the `CreateRunRequest` input type, background run spawning, pause/resume/cancel signal dispatch, external input injection via `submit_input`, and the per-run SQLite path convention.

## Specification

### CreateRunRequest

`CreateRunRequest` MUST contain:
- `goal: serde_json::Value` — the initial goal artifact payload

### RunManager

`RunManager` is a `Clone` + `Send` + `Sync` high-level lifecycle service. It MUST hold:
- `config: EurekaConfig` — runtime configuration shared across managed runs
- `persistence: Arc<dyn RunPersistence>` — durable run and checkpoint persistence
- `db_directory: Option<PathBuf>` — optional base directory for per-run SQLite databases
- `active: Arc<Mutex<HashMap<uuid::Uuid, Arc<Mutex<Option<mpsc::Sender<SchedulerSignal>>>>>>>` — map from run UUID to the scheduler signal channel for that run

`RunManager::new(config, persistence, db_directory)` constructs a manager.

### Per-run SQLite path

When `db_directory` is `Some(dir)`, the per-run SQLite path MUST be `dir/{run_id}.sqlite`.

### create_run

`create_run(request)` MUST:
1. Generate a `uuid::Uuid::now_v7()` as the run ID
2. Create a `RunRecord::new(run_id, config.graph, request.goal)` (initial status `Created`)
3. Persist the record via `persistence.save(record)`
4. Spawn the run in the background via `spawn_run`
5. Return the run UUID immediately

### spawn_run (internal)

`spawn_run(run_id, goal, checkpoint)` MUST:
1. Create a signal slot `Arc<Mutex<Option<mpsc::Sender<SchedulerSignal>>>>` initialized to `None`
2. Insert the slot into the `active` map; MUST return `EngineError::Run` if the run ID is already active
3. Spawn a `tokio` task that:
   a. Constructs `Session::new(config, &run_id.to_string(), db_path)`
   b. Calls `session.set_checkpoint_store(persistence.clone())`
   c. Calls `session.set_event_store(persistence.clone())`
   d. Calls `session.set_scheduler_signal_sink(slot.clone())`
   e. If `checkpoint` is `Some`, calls `session.resume_with_store(goal, Some(persistence), checkpoint)`; otherwise calls `session.run_with_store(goal, Some(persistence))`
   f. On error, logs the error at `ERROR` level with `run_id` and `error` fields
   g. On completion, sets the slot to `None` and removes the run from the `active` map

### pause_run

`pause_run(run_id)` MUST send `SchedulerSignal::Pause` to the active run via `send_signal`. It MUST return `EngineError::Run` if the run is not in the `active` map or if the scheduler slot is `None` (not yet ready).

### cancel_run

`cancel_run(run_id)` MUST send `SchedulerSignal::Cancel` to the active run via `send_signal`. Same error conditions as `pause_run`.

### resume_run

`resume_run(run_id)` MUST:
1. Load the run record; return `EngineError::Run` if not found
2. Verify `record.status == RunStatus::Paused`; return `EngineError::Run` otherwise
3. Load the latest checkpoint; return `EngineError::Run` if no checkpoint exists
4. Call `spawn_run(run_id, record.goal, Some(checkpoint))`

### submit_input

`submit_input(run_id, node_id, port, artifact)` injects a typed artifact into a paused run's checkpoint. It MUST:
1. Load the run record; return `EngineError::Run` if not found
2. Verify `record.status == RunStatus::Paused`; return `EngineError::Run` if not paused
3. Construct a validation session via `Session::new(config, &run_id.to_string(), None)` and call `session.validate_input(&node_id, &port, &artifact.kind)`; propagate any error
4. Load the latest checkpoint; return `EngineError::Run` if no checkpoint exists
5. Capture `expected = checkpoint.revision`
6. Call `checkpoint.inject_input(node_id, port, artifact)`; propagate `PersistenceError::InputConflict` as `EngineError::Store`
7. Set `checkpoint.reason = CheckpointReason::InputAccepted`
8. Save via `persistence.save_checkpoint(checkpoint, Some(expected))`; propagate errors
9. Return the updated checkpoint

### get_run

`get_run(run_id)` MUST delegate to `persistence.get(run_id)` and map `io::Error` to `EngineError::Store`.

### list_runs

`list_runs()` MUST delegate to `persistence.list()` and map errors to `EngineError::Store`.

### get_checkpoint

`get_checkpoint(run_id)` MUST delegate to `persistence.load_checkpoint(run_id)` and map errors to `EngineError::Store`.

### get_events

`get_events(run_id)` MUST delegate to `persistence.load_events(run_id)` and map errors to `EngineError::Store`.
