## Abstract

Defines the `Node` trait — the fundamental processing unit of the graph — along with its associated types: `PortMsg`, `Emit`, `NodeCtx`, `NodeError`, `NodeUsage`, and `BoxedNode`.

## Specification

### PortMsg

A `PortMsg` carries an artifact arriving on a specific input port. It MUST contain:
- `port: PortId` — the port on which the message arrived
- `artifact: Artifact`

### Emit

An `Emit` carries an artifact to be delivered on a specific output port. It MUST contain:
- `port: PortId` — the output port name
- `artifact: Artifact`

### NodeCtx

A `NodeCtx` is the runtime context provided to a node during processing. It MUST contain:
- `node_id: String` — the unique ID of the node being activated
- `node_kind: String` — the kind string of the node being activated
- `round: u32` — the current scheduler round (zero-indexed)
- `cancel: tokio_util::sync::CancellationToken` — a cancellation token for graceful shutdown
- `event_tx: Option<mpsc::Sender<SchedulerEvent>>` — optional channel for emitting observability events

A node MUST check `ctx.is_cancelled()` or the cancellation token on long-running operations and return `NodeError::Cancelled` if cancellation is detected.

### NodeError

A node MAY return any of the following errors from `process`:
- `Agent(String)` — an agent-specific error
- `PortKind { port, expected: &'static str, got }` — artifact kind does not match expected port kind
- `Timeout(String)` — the node exceeded its time budget
- `Cancelled` — the node was cancelled
- `Internal(String)` — a critical internal error

### NodeUsage

A `NodeUsage` MUST contain:
- `input_tokens: u64` — prompt/input tokens consumed
- `output_tokens: u64` — completion/output tokens consumed
- `total_tokens: u64` — total tokens; when the provider omits a separate aggregate, MUST equal `input_tokens + output_tokens`
- `cost_usd: f64` — best-effort USD cost; MUST be `0.0` when no per-model pricing is configured

`NodeUsage` MUST implement `Add` and `AddAssign` by summing each field independently.

Non-LLM nodes (control nodes, mock nodes) MUST return `NodeUsage::default()` (all zeros).

`NodeUsage::from_rig_usage(input, output, total, pricing)` MUST:
1. Set `total_tokens` to `total` when `total > 0`, otherwise to `input + output`
2. Set `cost_usd` using `pricing.cost(input, output)` when pricing is `Some`, otherwise `0.0`

### Node trait

The `Node` trait MUST declare two methods:
1. `fn ports(&self) -> PortSpec` — declares the node's input and output ports
2. `async fn process(&self, ctx: &NodeCtx, inputs: Vec<PortMsg>) -> Result<(Vec<Emit>, NodeUsage), NodeError>`

`process` receives all available inputs for the current activation: all required inputs that have arrived plus any optional inputs that have arrived. For a single-input node this is exactly one `PortMsg`. For a multi-input node it is one `PortMsg` per populated port.

`process` MUST return `(emits, usage)` where `emits` is a `Vec<Emit>` (may be empty) and `usage` is a `NodeUsage`.

`Node` MUST be `Send + Sync`.

### BoxedNode

`BoxedNode` wraps an `Arc<dyn Node>` and implements `Clone`. It MUST delegate `ports()` and `process()` to the inner node. It exists to allow heterogeneous node collections in a single registry without requiring `Clone` on `Node`.
