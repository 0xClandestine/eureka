## Abstract

Defines the complete `EurekaConfig` schema, the layered loading strategy, all sub-configuration types, and the environment variable aliasing rules.

## Specification

### Loading strategy

`EurekaConfig::load(config_path)` MUST merge configuration from these sources in order (later wins):
1. `DEFAULT_TOML` — the bundled default string; MUST be valid and complete
2. Config file — if an explicit path is given and exists; if the path does not exist, MUST return `ConfigError::FileError`; if no path is given, tries `eureka.toml` in the working directory silently
3. Environment variables — all variables with the `EUREKA_` prefix

`DEFAULT_TOML` is the source of truth for default values of scalar and nested-struct fields. Collection fields (`HashMap`, `Vec`) and `Option` fields whose natural default is empty/`None` MAY use `#[serde(default)]` instead of an explicit entry in `DEFAULT_TOML`; this is not a violation. All other fields MUST have an explicit default in `DEFAULT_TOML` so that a minimal config file (or no config file) produces a fully operational configuration.

### EurekaConfig

`EurekaConfig` MUST contain:
- `graph: String` — path to the YAML manifest file; default `"example/coscientist.yml"`
- `provider: ProviderConfig`
- `scheduler: SchedulerConfig`
- `budget: Budget`
- `agent: AgentConfig` — global LLM defaults for all agents
- `agent_overrides: HashMap<String, AgentConfig>` — per-agent overrides keyed by agent ID; defaults to empty
- `tracing: TracingConfig`
- `rag: Option<RagConfig>` — absent or `enabled = false` disables RAG; defaults to absent. The `RagConfig` fields are specified in SPEC-0018.

### ProviderConfig

`ProviderConfig` MUST contain:
- `kind: ProviderKind`
- `generation_model: Option<String>` — default model ID; falls back to `"deepseek/deepseek-v4-flash"` at session build time if absent
- `agent_models: HashMap<String, String>` — per-agent model IDs; keyed by agent name; defaults to empty
- `pricing: Option<Pricing>` — if `None`, cost is not tracked and only token/time/round backstops fire

### ProviderKind

`ProviderKind` MUST be one of: `anthropic`, `openai`, `openrouter`, `gemini`, `groq`, `mistral`, `cohere`, `deepseek`, `perplexity`, `together`, `xai`, `ollama`. These are the serde-renamed lowercase variants.

### Pricing

`Pricing` MUST contain:
- `input_per_million: f64` — USD per million prompt tokens; defaults to `0.0`
- `output_per_million: f64` — USD per million completion tokens; defaults to `0.0`

`Pricing::cost(input_tokens, output_tokens)` MUST compute `(input_tokens / 1_000_000) * input_per_million + (output_tokens / 1_000_000) * output_per_million`.

`Pricing::is_configured()` MUST return `true` if either rate is greater than `0.0`.

### Budget

`Budget` MUST contain:
- `max_cost_usd: f64` — default `25.0`
- `max_tokens: u64` — default `5_000_000`
- `max_wallclock: f64` — wall-clock seconds; default `2700.0` (45 minutes); accepts a float (seconds) or a human-readable string (`"30s"`, `"45m"`, `"2h"`) in TOML
- `max_rounds: u32` — default `12`

`max_wallclock` MUST also be deserializable via the aliases `max_wallclock_secs`, `maxwallclock`, and `maxwallclocksecs`. The alias `maxwallclock` (no underscore) is required for the environment variable `EUREKA_BUDGET_MAXWALLCLOCK` because figment splits env var keys on `_`.

### SchedulerConfig

`SchedulerConfig` MUST contain:
- `max_in_flight: usize` — maximum concurrent node activations; default `8`

### AgentConfig

`AgentConfig` MUST contain:
- `temperature: f64` — LLM sampling temperature; default `0.7`
- `max_iterations: u32` — maximum turns in the agentic loop; default `10`

### TracingConfig

`TracingConfig` MUST contain:
- `enabled: bool` — whether to persist scheduler events to the database; default `false`
- `max_file_bytes: u64` — reserved; default `0`
- `include_artifacts: bool` — whether to include artifact payloads in persisted events; default `true`

### Environment variable mapping

Figment maps environment variables with prefix `EUREKA_` to config fields by splitting the remainder on `_`. For example:
- `EUREKA_GRAPH` → `graph`
- `EUREKA_PROVIDER_KIND` → `provider.kind`
- `EUREKA_SCHEDULER_MAXINFLIGHT` → `scheduler.max_in_flight`
- `EUREKA_BUDGET_MAXWALLCLOCK` → `budget.maxwallclock` (via alias)

Fields whose names contain underscores MUST be settable via alias keys that omit the inner underscore, because the figment `_`-split mapping would otherwise create an unwanted nesting.
