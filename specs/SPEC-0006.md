## Abstract

Defines `GraphSpec` and `GraphNodeSpec` — the pure topology data structures that fully describe a graph run without any I/O, LLM calls, or subprocess state.

## Specification

### GraphNodeSpec

A `GraphNodeSpec` MUST contain:
- `id: String` — unique node identifier within this graph; MUST be unique across all nodes
- `kind: String` — the node type identifier used for registry lookup; for LLM agents the kind equals the id; for control nodes it is the `kind` field from the manifest
- `config: serde_json::Value` — per-instance configuration; defaults to `null` when absent
- `description: Option<String>` — optional human-readable description; not used by the runtime

### GraphSpec

A `GraphSpec` MUST contain:
- `name: Option<String>` — optional human-readable graph name
- `description: Option<String>` — optional description; not used by the runtime
- `nodes: Vec<GraphNodeSpec>` — all nodes in the graph
- `edges: Vec<Edge>` — all directed edges connecting node ports
- `metadata: serde_json::Value` — optional metadata; not used by the runtime

Every node ID referenced in `edges` MUST appear in `nodes`.

### Source node detection

A source node is a node that has no non-feedback inbound edges. Source nodes receive the initial goal injection at run start (see SPEC-0012).

`GraphSpec::source_node_ids()` MUST return the IDs of all nodes for which no non-feedback edge has that node as `to_node`. Feedback edges (`Edge::feedback == true`) MUST NOT be counted when determining source status.

A node that only receives inputs via feedback edges MUST be treated as a source node and MUST receive the initial goal injection.

### GraphError

The following graph error variants MUST exist:
- `ParseError(String)` — manifest could not be read or parsed
- `PortKindMismatch(String)` — output kind does not match input kind on an edge
- `DanglingPort(String)` — required input port has no inbound edges
- `UnreachableNode(String)` — node not reachable from any source
- `UngovernedCycle(String)` — a strongly connected component has no governor node
- `MissingSink(String)` — no node produces a terminal output artifact
- `UnknownNode(String)` — an edge references a node not in the node list
- `UnknownPort(String)` — an edge references a port not declared on the node

## Rationale

`GraphSpec` is intentionally free of I/O and LLM state so it can be validated, serialized, and inspected before any execution begins. The only path to a `GraphSpec` is via the manifest loader (see SPEC-0008).
