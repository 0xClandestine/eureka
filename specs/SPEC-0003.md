## Abstract

Defines the port declaration types used by every graph node: `PortDef`, `PortDirection`, `PortSpecEntry`, `PortSpec`, and `PortId`.

## Specification

### PortId

`PortId` is a type alias for `String`. By convention its value is `<node_id>.<port_name>` (e.g. `generation.out`). The runtime enforces no structure on this string beyond using it as a map key.

### PortDirection

`PortDirection` MUST be one of two variants: `Input` or `Output`. There are no other valid directions.

### PortDef

`PortDef` is the manifest-facing declaration of a single port. It MUST contain:
- `port: String` — the port name as used in graph edge definitions
- `kind: ArtifactKind` — the artifact kind this port accepts (inputs) or emits (outputs)
- `required: Option<bool>` — whether the port is required; applies only to input ports

When `required` is `None` or omitted, the port MUST be treated as required (`true`) for inputs. This default preserves backward compatibility.

`PortDef` MUST NOT be used to declare an output port as required; output ports are always optional regardless of any `required` value.

### PortSpecEntry

`PortSpecEntry` is the resolved representation of a single port used internally by the validator and scheduler. It MUST contain:
- `name: String` — the port name
- `direction: PortDirection`
- `kind: ArtifactKind`
- `required: bool`

Converting a `PortDef` to an input `PortSpecEntry` via `to_input_spec()` MUST set `required` to `self.required.unwrap_or(true)`.

Converting a `PortDef` to an output `PortSpecEntry` via `to_output_spec()` MUST set `required` to `false`.

### PortSpec

`PortSpec` holds the complete port declaration for a node: `inputs: Vec<PortSpecEntry>` and `outputs: Vec<PortSpecEntry>`.

`PortSpec::from_defs(inputs: &[PortDef], outputs: &[PortDef])` MUST convert each input `PortDef` to an input `PortSpecEntry` and each output `PortDef` to an output `PortSpecEntry`.

`PortSpec::input_kind(name)` MUST return the kind of the named input port, or `None` if no such port exists.

`PortSpec::output_kind(name)` MUST return the kind of the named output port, or `None` if no such port exists.

`PortSpec::required_inputs()` MUST return the names of all input ports where `required == true`.

`PortSpec::is_input_required(name)` MUST return `true` if and only if a port with that name exists and has `required == true`.

## Rationale

`PortDef` uses `Option<bool>` for `required` rather than `bool` with a `#[serde(default)]` so that manifests omitting the field are distinguishable from manifests that explicitly set it, allowing accurate backward-compatibility defaulting.
